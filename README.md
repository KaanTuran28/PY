## English

A collection of small Python learning projects — data-analysis notebooks, a Discord bot, turtle-graphics drawings and a few experiments. Each folder is self-contained and has its own README and LICENSE.

### Projects

| Folder | What it is |
|---|---|
| `Data-analysis/` | Jupyter notebook analysing Turkish software-developer salaries (CSV dataset). |
| `Data-analysis-2/` | Jupyter notebook analysing the Turkey second-hand car market (CSV dataset). |
| `Analysis-with-Python-link/` | A small script-based data-analysis example. |
| `DC-ROL-BOT/` | A Discord bot (discord.py) with commands and events — role assignment and activity/presence. |
| `Python-cumhuriyet/` | A `turtle` graphics drawing themed around Republic Day. |
| `Python-kalp/` | A `turtle` graphics heart drawing. |
| `python-Ransomware/` | An **educational** file encrypt/decrypt proof-of-concept, written for self-study of how symmetric encryption works. See the note below. |

### Running

Most scripts only need Python 3, e.g. `python "Python-kalp/kalp.py"`.

- The notebooks (`Data-analysis`, `Data-analysis-2`) open in Jupyter and expect their CSV files alongside them.
- `DC-ROL-BOT` needs `discord.py` and a bot token (keep the token out of source control).
- The turtle drawings open a graphics window.

> **Educational note:** `python-Ransomware/` is a learning proof-of-concept for understanding file encryption, meant to be run only on your own test files in an isolated environment. Do not run it against data you care about or any system you do not own. It is shared for study only — using such code against others' systems is illegal.

### Çalıştırma

Çoğu betik için yalnızca Python 3 yeterli, ör. `python "Python-kalp/kalp.py"`.

- Defterler (`Data-analysis`, `Data-analysis-2`) Jupyter'da açılır ve CSV dosyalarını yanlarında bekler.
- `DC-ROL-BOT` için `discord.py` ve bir bot token'ı gerekir (token'ı sürüm kontrolünden uzak tutun).
- Turtle çizimleri bir grafik penceresi açar.

> **Eğitim notu:** `python-Ransomware/`, dosya şifrelemeyi anlamaya yönelik bir öğrenme kanıt-çalışmasıdır; yalnızca izole bir ortamda kendi test dosyalarınız üzerinde çalıştırılmak içindir. Önem verdiğiniz verilere veya sahibi olmadığınız bir sisteme karşı çalıştırmayın. Yalnızca öğrenme amacıyla paylaşılmıştır; böyle bir kodu başkalarının sistemlerine karşı kullanmak yasa dışıdır.
